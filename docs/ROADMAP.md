## Arc entry format

When populated, each arc follows this structure:

    ### Arc: <name>

    **Theme:** <one-line strategic goal>
    **Started:** <YYYY-MM-DD>
    **Estimated cycles:** <N>
    **Cycles elapsed:** <K>
    **Status:** in-progress | stalled | near-completion | complete

    **Milestones:**
    - [x] Cycle X: <description, with Future.md item references>
    - [ ] Cycle X+1: <description>
    - ...

    **Vision alignment:** <how the arc serves the universal math inference engine vision>

    **Why this arc was chosen:** <plan-critic's reasoning at selection time>

    **Reopen / extend trigger:** <concrete condition, e.g. "Future.md #N becomes available" or "user explicitly requests follow-up">
